# ShardScript Asset Repository

Welcome to the official public asset repository for the **ShardScript** programming language! This repository hosts high-quality graphical media, banners, SVGs, PNGs, and Adobe Illustrator source files related to ShardScript. 

These assets are made public to support the community, ecosystem builders, and content creators.

## 📂 Repository Structure

* `/logos` — Official ShardScript logos (`.svg`, `.png`).
* `/icons` — Official ShardScript icons (`.ico`, `.icns`).
* `/banners` — High-resolution headers for documentation, socials, and blogs.
